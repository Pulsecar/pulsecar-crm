# Pulsecar — мобильное приложение (iOS + Android)

Один код на React Native / Expo (SDK 57) — собирается и для App Store, и для Google Play.
Стиль и контент взяты с pulsecar.pl: тёмная тема `#101113`, акцент `#1BF372`, шрифт Poppins
(кириллица дорисована из Montserrat — у Poppins её нет).

## Что внутри
- **Главная** — статус «открыто/закрыто» по варшавскому времени, звонок, соцсети, акции (тест, проверка перед покупкой 300 zł, «Посоветуй другу»), услуги.
- **Цены** — весь прайс с сайта (45 позиций) с поиском + список услуг. Нажатие на позицию → запись с подставленной услугой.
- **Тест** — «Что с машиной?»: 9 симптомов → уточнение → частые причины + подходящая услуга и цена.
- **Запись** — форма как на сайте; заявка попадает в терминарз CRM («Не распределено»), запасной вариант — WhatsApp / SMS.
- **Контакты** — адрес, маршрут, часы работы, время в пути, гарантия, соцсети.
- **Посоветуй другу** — код ИМЯ-1234 и «Поделиться».
- **Карта Pulse Points** (центральная вкладка) — QR, который меняется каждые 30 с, 6-значный код для ручного ввода, баланс, уровень, правила.
- **Профиль** — вход по SMS, текущий заказ со статусом, записи, мои авто с историей заказов и позициями (прямо из CRM), история баллов, выход, удаление аккаунта.
- Тест симптомов и контакты открываются с главной и из профиля.
- Языки: PL / EN / UA / RU (автоматически по языку телефона).

## Сервер
Кабинет, баллы и заявки работают через CRM `panel` (папка рядом, инструкция в её README).
Адрес сервера по умолчанию: `https://panel.pulsecar.tech`. Другой адрес задаётся при сборке:
`EXPO_PUBLIC_API_URL=https://... npx expo start`.
Кнопка «Посмотреть демо» на экране входа появляется только при `EXPO_PUBLIC_DEMO=1`. Для магазинной сборки её не включайте.

## Где что менять
- Цены, услуги, контакты, часы, тест — `src/data.ts`
- Тексты интерфейса — `src/i18n.ts`
- Цвета — `src/theme.ts`
- Иконка/заставка — `assets/icon.png`, `assets/android-icon-*.png`, `assets/splash-icon.png` (логотип Pulsecar).

## Запуск на своём телефоне (5 минут)
1. Установите Node.js 20+ (nodejs.org).
2. В папке проекта: `npm install`, затем `npx expo start`.
3. Установите на телефон **Expo Go** и отсканируйте QR-код.

## Публикация в магазины
Нужны аккаунты: **Apple Developer** ($99/год) и **Google Play Console** ($25 один раз). Бесплатный аккаунт на expo.dev.

```bash
npm i -g eas-cli
eas login
eas build:configure
eas build --platform android --profile preview   # APK для теста на Android
eas build --platform all --profile production    # сборки для магазинов (Mac не нужен)
eas submit --platform ios
eas submit --platform android
```
Идентификатор приложения: `pl.pulsecar.app` (можно поменять в `app.json` до первой публикации).
Для магазинов понадобятся: ссылка на политику конфиденциальности (есть на сайте), скриншоты, описание.
