# Задача: подключить модуль «ИИ-запчастист» к CRM Pulsecar

Ты работаешь с кодом CRM Pulsecar. В архиве `ai-parts` лежит **готовый модуль** «ИИ-запчастист»:
отдельный сервис (Node.js + SQLite, Docker), виджет для страницы wyceny, страница «Интеграции»
и расширение Chrome для partslink24. Модуль протестирован (`npm test` — 9 тестов проходят).
Твоя задача — **развернуть сервис рядом с CRM и встроить его в CRM**. Код модуля без необходимости
не переписывай; если что-то нужно поменять — объясни зачем.

Сначала изучи код CRM и пришли план (что меняешь, какие файлы, как деплой и откат).
Изменения в базе CRM и деплой — только после моего «ок». Перед деплоем — бэкап базы CRM.

---

## Что делает модуль (кратко)

В каждой wycenie / zleceniu — кнопка **«Подбор запчастей (ИИ)»**. Менеджер пишет, что нужно
(например «замена комплекта ГРМ + помпа + масло, фильтр + свечи»), выбирает уровень и срочность.
Агент (Claude) работает как профессиональный запчастист:

1. расшифровывает VIN (NHTSA vPIC + свои проверки; отличает авто из США);
2. раскладывает работу на полный список деталей (комплекты, жидкости, датчики, крепёж);
3. ищет **оригинальные номера**: история wycen автосервиса → partslink24 по VIN (через расширение,
   в сессии менеджера) → форумы и каталоги в интернете; номер считается подтверждённым,
   только если его подтверждают ≥2 независимых источника, один из них — каталог или проверенная история;
4. если у модели несколько вариантов детали (например, 3 тормозные системы у BMW M3 G80) —
   определяет вариант **только по VIN, без вопросов**: коды заводских опций из partslink24, история по этому VIN,
   для машин из США — оконная наклейка (window sticker) и аукционные истории, найденные по полному VIN.
   Если по VIN определить нельзя — ставит в wycenę **оба варианта** с пометкой «заказать оба, лишний вернуть»
   (вопросы менеджеру по умолчанию выключены, включаются в «Правилах подбора»: `askManager`);
5. ищет аналоги в Inter Cars по номерам (OE и номера производителей) → цены закупки и наличие через WebAPI;
6. отдаёт позиции: 3 уровня (эконом / средний / OE), цена клиенту по правилам наценки,
   статус «подтверждено» / «проверьте», источники со ссылками.

Выбранные позиции **CRM сама сохраняет в wycenę** (виджет вызывает колбэк `onAddItems`).
Сервис в базу CRM не пишет. Заказ у поставщика — только по кнопке менеджера и только для подтверждённых позиций.

## Шаг 1. Развернуть сервис на VPS

- VPS Hostinger, Ubuntu 24.04, Docker. Уже есть проекты `autoservice-smm-bot` (Caddy на 80/443),
  `panel` (`pulsecar-panel`, порт 3100), `pulsecar-site`. Выясни, где CRM.
- Положи папку `ai-parts/service` на сервер отдельным Docker-проектом (`docker-compose.example.yml` → `docker-compose.yml`).
- Создай `.env` по `.env.example`:
  - `MASTER_KEY` и `CRM_SHARED_SECRET` — сгенерировать (команда в `.env.example`), **не коммитить**;
  - `CORS_ORIGINS` — адрес CRM;
- Опубликуй сервис через существующий Caddy по HTTPS (например `ai-parts.<домен CRM>` или путь `/ai-parts/`).
- Проверка: `GET /health` → `{"ok":true}`.

## Шаг 2. Токены CRM → сервис

Сервис доверяет только токенам, подписанным `CRM_SHARED_SECRET` (HMAC-SHA256). Формат:
`base64url(JSON payload) + "." + base64url(HMAC_SHA256(первая_часть, secret))`.

payload: `{ "ws": "<id автосервиса>", "uid": "<id пользователя>", "role": "manager"|"admin"|"system", "wid": "<id wyceny, необязательно>", "exp": <unix-время> }`

- `ws` — идентификатор автосервиса (организации) в CRM. CRM планируется продавать другим автосервисам,
  поэтому всё в модуле разделено по `ws`.
- Срок жизни: 10–15 минут для виджета и страницы настроек; виджет может получать новый токен через функцию.
- Роль `admin` — только для администраторов автосервиса (страница «Интеграции»).
- Роль `system` — для фонового экспорта истории (шаг 5).

Пример (Node.js):
```js
import crypto from 'node:crypto';
function aiPartsToken(payload, secret) {
  const part = Buffer.from(JSON.stringify(payload)).toString('base64url');
  const sig = crypto.createHmac('sha256', secret).update(part).digest('base64url');
  return `${part}.${sig}`;
}
// aiPartsToken({ ws: workshop.id, uid: user.id, role: 'manager', wid: wycena.id, exp: Math.floor(Date.now()/1000) + 900 }, process.env.AI_PARTS_SECRET)
```
Пример (PHP):
```php
function aiPartsToken(array $p, string $secret): string {
  $b64 = fn($s) => rtrim(strtr(base64_encode($s), '+/', '-_'), '=');
  $part = $b64(json_encode($p, JSON_UNESCAPED_UNICODE));
  return $part . '.' . $b64(hash_hmac('sha256', $part, $secret, true));
}
```
Токен выпускает **бэкенд** CRM (секрет в браузер не попадает) — например эндпоинт
`GET /api/ai-parts/token?wycenaId=…` с проверкой прав пользователя на эту wycenę.

## Шаг 3. Кнопка в wycenie и zleceniu

На странице каждой wyceny и каждого zlecenia:
```html
<div id="ai-parts"></div>
<script src="https://<адрес сервиса>/widget.js"></script>
<script>
AiParts.mount(document.getElementById('ai-parts'), {
  serviceUrl: 'https://<адрес сервиса>',
  token: '<токен с role=manager и wid этой wyceny>',
  wycenaId: '<id wyceny>',
  vehicle: { vin, make, model, engine, year, mileage },   // ИЗ ЭТОЙ wyceny
  defaultLevel: 'middle',                                // из карточки клиента, если есть
  existingItems: [/* уже добавленные позиции: { name, oeNumber, articleNumber } — чтобы не дублировать */],
  onAddItems: async (items) => { /* POST в CRM: сохранить позиции в эту wycenę */ }
});
</script>
```
Если фронтенд CRM — SPA (React/Vue и т.п.), оберни `AiParts.mount` в компонент; виджет рисуется в Shadow DOM
и стили CRM не ломает.

`onAddItems(items)` получает массив позиций. Сохрани каждую как позицию-запчасть wyceny:

| Поле item | Куда в CRM |
| --- | --- |
| `name`, `quantity`, `unit` | название, количество, единица |
| `brand`, `articleNumber` | производитель и номер детали |
| `oeNumber` | OE-номер (добавь поле, если нет) |
| `supplier`, `supplierSku` | поставщик и его код (для Inter Cars `supplierSku` = SKU/TOW_KOD для заказа) |
| `purchaseNet` | цена закупки netto |
| `priceNet`, `priceGross` | цена клиенту (наценка уже посчитана по правилам) |
| `level` | economy / middle / oe |
| `status: 'ai_draft'` | статус позиции «Черновик ИИ» (добавь статус) |
| `needsCheck`, `checkReason` | флаг «проверьте» + причина: **такую позицию нельзя заказывать**, пока менеджер не подтвердит |
| `orderBothVariants`, `variants` | вариант не определён по VIN: заказать **все** варианты из `variants`, лишний вернуть (заказ разрешён) |
| `offers` | все 3 варианта — сохрани (JSON), чтобы менеджер мог переключить уровень в wycenie |
| `evidence` | источники номера (JSON) — показать по клику |
| `aiJobId`, `aiItemId` | ссылки на подбор (для обучения и статистики) |

Повторный подбор в той же wycenie не должен дублировать позиции (сверяй по `oeNumber`/`articleNumber`).

## Шаг 4. Ustawienia → «Integracje»

Добавь в настройки CRM раздел **«Integracje» (ИИ-запчастист)** — только для администратора.
Простейший вариант: `<iframe src="https://<адрес сервиса>/admin?token=<токен role=admin>">`.
Там: ключи всех сервисов (хранятся зашифрованно, после сохранения — маской), «Проверить подключение»,
«Правила подбора» (бренды по уровням, наценки, комплекты, чёрный список), ключи расширения partslink24, статистика.

Что вводит админ:
- **Anthropic (Claude)** — API key (обязательно).
- **Inter Cars WebAPI** — `token_url`, `client_id`, `client_secret` (OAuth2 client credentials) **или** готовый токен.
  В CRM уже есть интеграция с Inter Cars (бот wycen) — **посмотри, как она получает токен**, и подставь те же
  параметры (адрес токена в документации IC не указан). Плюс логин/пароль к CSV-файлам IC.
- partslink24 — паролей нет; выдаются ключи расширения.
- DAT, TecDoc, TecRMI, ProfiAuto, Allegro — карточки-заготовки, заработают после договоров (реализации провайдеров — TODO).

## Шаг 5. История wycen → обучение ассистента

Ассистент опирается на историю автосервиса (что ставили на какой VIN/мотор, что вернули).
Сделай экспорт из базы CRM в модуль: `POST /api/history/import` с токеном `role: system`, тело `{ "rows": [...] }`,
пачками по 1000:

| Поле | Значение |
| --- | --- |
| `source_id` | уникальный id позиции в CRM (для повторной выгрузки без дублей) |
| `wycena_id` | id wyceny/zlecenia |
| `vin`, `make`, `model`, `engine_code`, `year` | авто |
| `job_text` | текст работ wyceny |
| `part_name`, `brand`, `article_number`, `oe_number` | деталь |
| `supplier`, `price_net`, `sale_net` | поставщик, закупка, продажа |
| `verified` | 1 — деталь реально установлена (zlecenie закрыто) |
| `returned` | 1 — деталь возвращали / не подошла |
| `created_at` | дата |

**Без имён, телефонов и e-mail клиентов (RODO).**
1) Разовая выгрузка всей истории. 2) Далее — при закрытии zlecenia (verified=1) и при оформлении возврата (returned=1)
отправлять изменённые строки. Если в CRM нет признака возврата — добавь.

## Шаг 6. Каталог Inter Cars

API Inter Cars **не ищет по OE-номеру** — только по своему SKU/индексу. Поэтому модуль держит локальный
каталог из CSV `ProductInformation` (TOW_KOD, IC_INDEX, TEC_DOC, ARTICLE_NUMBER, MANUFACTURER…) и сопоставляет
найденные номера с SKU. Настрой ежедневный импорт (cron после 05:30):
`docker exec pulsecar-ai-parts node scripts/import-ic-csv.js --ws <id автосервиса> --url <URL файла>`
Файлы: https://data.webapi.intercars.eu/customer (BasicAuth, логин/пароль CSV из «Интеграций»).
Уточни точное имя файла в каталоге `ProductInformation` после входа.

## Шаг 7. Заказ (после пилота)

Кнопка «Заказать у поставщиков» в wycenie — только для принятых позиций без `needsCheck`.
Для Inter Cars в модуле есть `createRequisition` (`POST /ic/sales/requisition`) в `src/providers/intercars.js` —
либо используй существующую логику заказа CRM. Подтверждение заказа (`/confirm`) — отдельным действием менеджера.

## Шаг 8. Расширение partslink24 для менеджеров

Папка `ai-parts/extension`. Установка: Chrome → `chrome://extensions` → «Режим разработчика» →
«Загрузить распакованное» → папка `extension`. В настройках расширения: адрес сервиса и ключ
(выдаётся в «Integracje» → «Расширение partslink24»). Менеджер просто должен быть залогинен в partslink24 в этом Chrome.
Расширение работает в его сессии, по одной задаче, в человеческом темпе, ничего не заказывает и пароли не хранит.

## Критерии готовности

- [ ] Сервис отвечает по HTTPS, `/health` ок; `.env` с секретами не в git.
- [ ] Кнопка есть в каждой wycenie и zleceniu; данные авто берутся из той wyceny, где нажата кнопка.
- [ ] Подбор по реальному VIN и тексту добавляет позиции в ту же wycenę со статусом «Черновик ИИ».
- [ ] Позиции «проверьте» нельзя заказать без подтверждения.
- [ ] «Integracje» доступна только админу; ключи после сохранения видны маской; «Проверить подключение» работает для Claude и Inter Cars.
- [ ] История wycen выгружена (статистика в «Integracje» показывает число строк), новые закрытые zlecenia отправляются.
- [ ] Каталог Inter Cars импортирован (статистика показывает число товаров), cron настроен.
- [ ] Расширение установлено у одного менеджера, подбор по VIN европейского авто показывает шаги «partslink24: …».
- [ ] Инструкция отката: остановить контейнер `pulsecar-ai-parts` и убрать кнопку — CRM работает как раньше.
