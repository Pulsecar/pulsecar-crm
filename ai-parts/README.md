# ИИ-запчастист Pulsecar — модуль для CRM

Подбор запчастей по кнопке в wycenie: VIN + текст работ → оригинальные номера (partslink24, история,
форумы и каталоги) → проверка → аналоги, цены и наличие Inter Cars → позиции в wycenę.

```
ai-parts/
├── ЗАДАЧА_ДЛЯ_ЧАТА_CRM.md   ← отправить в чат, где делалась CRM (инструкция по подключению)
├── service/                 ← сервис (Node.js 22, SQLite, Docker)
│   ├── src/
│   │   ├── server.js        HTTP API: подбор, интеграции, правила, история, мост расширения
│   │   ├── jobs.js          задачи подбора: запуск, пауза на вопрос, продолжение
│   │   ├── agent/           агент Claude: промт запчастиста, инструменты, цикл
│   │   ├── providers/       VIN (NHTSA), Inter Cars (API + CSV-каталог), история, partslink24
│   │   ├── integrations.js  «Интеграции»: ключи (AES-256-GCM), статусы
│   │   └── rules.js         «Правила подбора»: бренды, наценки, комплекты
│   ├── public/widget.js     кнопка + форма + результат для страницы wyceny
│   ├── public/admin.html    страница «Интеграции / Правила / Расширение / Статистика»
│   ├── scripts/try.js       проверка агента из консоли без CRM
│   ├── scripts/import-ic-csv.js  импорт каталога Inter Cars (CSV ProductInformation)
│   └── test/                тесты (npm test)
└── extension/               расширение Chrome для partslink24 (сессия менеджера)
```

## Быстрая проверка агента без CRM

```bash
cd service && npm install
echo "ANTHROPIC_API_KEY=sk-ant-..." > .env
node scripts/try.js --vin WBS43AY07PFP64494 --text "колодки тормозные передние и задние, датчики износа"
```
Агент покажет шаги, задаст вопрос, если вариант детали не определяется, и выведет результат.
В этом режиме partslink24 и Inter Cars выключены (нужны расширение и ключи) — проверяется логика поиска номеров.

## Важные ограничения

- API Inter Cars не ищет по OE-номеру: нужен ежедневный импорт CSV-каталога (см. задачу для CRM, шаг 6).
- partslink24 — только через расширение в сессии менеджера: один VIN на конкретный ремонт, человеческий темп,
  без хранения каталога. Для массовой автоматизации нужен договор с LexCom.
- DAT, TecDoc/TecRMI, ProfiAuto, Allegro — карточки в «Интеграциях» готовы, провайдеры подключаются после договоров.
- Стоимость: токены Claude + $10 за 1000 поисков в интернете (тарифы Anthropic); лимит подборов в месяц — в таблице `workshops`.
